# Data

`ship_VOCMN.csv` is the trajectory input used by the optional maritime
workflow. Each row contains one `trajectory_id` and a space-delimited sequence
of port IDs.

The manuscript describes the source as container-ship port-call trajectories
from ShipDT. Check the source provider's redistribution terms before publishing
this file in a public repository. The synthetic experiments do not require this
file: their paths are generated deterministically from a recorded seed.
